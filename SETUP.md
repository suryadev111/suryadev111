# Setup guide — suryadev111 GitHub profile

## Files in this pack

- `README.md` — profile page content
- `.github/workflows/metrics.yml` — automatically generates the analytics SVGs
- `github-stats.svg`, `top-languages.svg`, `contribution-calendar.svg`, and `achievements.svg` are generated by the workflow after its first successful run.

## Install

1. Open `https://github.com/suryadev111/suryadev111`.
2. Upload/replace `README.md` from this pack.
3. Upload `.github/workflows/metrics.yml` while preserving the folder path.
4. In the profile repository, open **Settings → Secrets and variables → Actions → New repository secret**.
5. Create a secret named `METRICS_TOKEN`.
6. Set its value to a GitHub Personal Access Token (classic) with no scopes for public profile metrics. If you later enable private-repository metrics, add only the scopes required by those features.
7. Open **Actions → Generate GitHub Profile Analytics → Run workflow**.
8. Wait for the workflow to finish, then refresh your profile README.

## Important

- The workflow uses the official `lowlighter/metrics` GitHub Action and commits generated SVG files into your profile repository.
- The first run is required before the local SVG image links in the README can render.
- GitHub's Actions settings must allow workflows to run. The workflow has `contents: write` permission so it can commit generated images.
- This setup creates a contribution calendar, language chart, overview statistics and achievements. It does not claim to calculate a separate current/longest contribution streak card.
- The featured repository names are based on the repositories visible in your supplied screenshot. Confirm the links exist and are public; edit them if your repository names differ.
- Third-party action releases and GitHub API availability can change. Check the official documentation if the action reports an error: https://github.com/lowlighter/metrics
